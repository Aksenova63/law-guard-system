# Функциональные требования

| ID требования | Название таска | Условие (Входные данные / Сценарий) | Результат |
| :--- | :--- | :--- | :--- |
| **FR-01** | `[TSK_01]` Отобразить главный экран | Открытие главной страницы системы. | Отображение кнопок "Войти" и "Зарегистрироваться". |
| **FR-02** | `[TSK_02]` Регистрация в системе | Заполнение полей, выбор роли (Клиент/Юрист). | Создание уникального ID, запись в БД. Переход к `[TSK_04]` (Юрист) или ЛК (Клиент). |
| **FR-03** | `[TSK_03]` Авторизация | Ввод данных, хеширование пароля. | Редирект в Личный кабинет на основе роли. |
| **FR-04** | `[TSK_04]` Выбор специализации (Юристы) | Ввод данных, загрузка диплома. | Проверка данных, запись в БД (статус `pending`), проверка админом. |
| **FR-05** | `[TSK_05]` Публикация запроса | Заполнение формы заявки. | Валидация, запись в БД, статус `open`. |
| **FR-06** | `[TSK_06]` Назначение исполнителя | Отклик юристов, таймер. | Смена статуса на `in_progress`, назначение юриста. |
| **FR-07** | `[TSK_07]` Закрытие сделки | Оплата. | Списание средств, статус `closed`. |
