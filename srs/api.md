### Реестр методов API (Аутентификация и авторизация)

| ID метода | Метод | URL Путь | JSON (Входные параметры) | Описание полей запроса | Статус ответа |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **REQ-LAW-001** | `POST` | `/auth/register` | <pre>{<br>  "email": "string",<br>  "name": "string",<br>  "phone": "string",<br>  "password": "string",<br>  "role": "string"<br>}</pre> | • `email` — уникальный логин (почта)<br>• `name` — ФИО пользователя<br>• `phone` — номер телефона (опционально)<br>• `password` — пароль (не менее 8 символов)<br>• `role` — роль в системе (`client` или `lawyer`) | • **201 Created** — успешно<br>• **400 Bad Request** — ошибка валидации данных<br>• **409 Conflict** — такой email уже занят |
| **REQ-LAW-002** | `POST` | `/auth/login` | <pre>{<br>  "email": "string",<br>  "password": "string"<br>}</pre> | • `email` — логин пользователя (почта)<br>• `password` — пароль для входа | • **200 OK** — успешный вход (система возвращает токен сессии)<br>• **401 Unauthorized** — неверный логин или пароль |
